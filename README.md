# Cognis

Cognis is an evidence-backed venture diligence workspace for analysts preparing investment decisions. It combines structured venture intake, assessment questions, evidence tracking, risk signals, and committee preparation in one auditable workflow.

## Current build

- Express backend served from `src/server.js`
- Prisma persistence with a local SQLite database
- Venture intake and generated assessment structure
- Analyst responses and evidence requests persisted through the API
- Live Binance Web3 token search, details, market ranking, and security audit integration
- Responsive desktop and mobile interface

## Run locally

```powershell
npm.cmd start
```

Open `http://localhost:3001`.

## Verify the live integration

```powershell
npm.cmd test
```

The test checks the Cognis health endpoint and live Binance token search, token details, market ranking, and token audit routes.

## Data status

The database includes seeded demonstration ventures for interface evaluation. Ventures created through the intake flow are stored as non-demo records. Binance evidence is requested live through the backend and is not generated by the frontend.
